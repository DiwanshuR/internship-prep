# Student Management System

## Description

A command-line Python application for managing
student information.

## Features

- Add students
- View all students
- Search students by name
- Delete students
- JSON data persistence
- Input validation
- Error handling

## Technologies

- Python
- JSON
- Object-Oriented Programming

## How to Run

1. Clone the repository
2. Open the project directory
3. Run:

python main.py
